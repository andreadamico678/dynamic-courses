# Part Introduction Author Prompt

You are writing `00-introduction.mdx` (`00-introduzione.mdx` for Italian courses, `sidebar.order: 0`) for a Part of a **Dynamic Courses** textbook.

## Required Structure
1. **Frontmatter:** `title` (`2–4` plain words), `description`, `sidebar.order: 0`. Do not import or render `<MindMap />`.
2. **`## Introduction` (`## Introduzione`):** Concise overview of what this Part solves, how its chapters connect, and any shared Part-wide taxonomy.
3. **`### Running Example` (`### Esempio Condiviso`):** Introduce one concrete physical/numerical system (using locked symbols from `symbols.yaml`) that the Part's chapters analyze sequentially. Keep the heading plain—never call it an "Anchor System".
4. **Chapter Roadmap:** Bulleted markdown links (`/dynamic-courses/<course-slug>/<part-dir>/<chapter-slug>/`) with Keyword-Only Bold (`1–4` words max).
