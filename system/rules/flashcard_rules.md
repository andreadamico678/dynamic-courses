# Obsidian Flashcard Rules

Flashcards remain standalone Obsidian Markdown files inside `courses/<course-slug>/flashcards/` using the Obsidian Spaced Repetition format (`Question?` / `?` / `Answer.`), separated by `---`.

---

### Core Rules

1. **Absolute Atomicity:** One discrete fact, relation, or precondition per card. Never write multi-bullet lists.
2. **Direct Engineering Tone:** Target 5–15 seconds per card; ban pompous phrasing.
3. **Triggers & Pivots:** Test the structural cue or key substitution, not 50-line proofs.
4. **Boundaries & Failure Modes:** Test exact preconditions and counterexamples.
5. **Decouple Mechanism from Syntax:** Separate intuitive meaning from formal equations.
6. **Bidirectional Paired Recall:** Pair Term $\to$ Property and Property $\to$ Term cards.
7. **LaTeX Rigor:** Wrap variables/formulas in `$...$` or `$$...$$`; never wrap math inside `==...==` highlight tags (`==term==: $x$`).
