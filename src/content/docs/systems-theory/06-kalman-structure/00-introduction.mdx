## Introduction

Transfer functions $W(s)$ describe only the externally coupled channel from input to output and silently erase any mode that cancels. Before synthesizing a state-feedback controller or state estimator, an engineer must test two structural properties of $(\mathbf{A}, \mathbf{B}, \mathbf{C})$: whether actuators steer every state (**controllability**) and whether sensors reconstruct every state (**observability**).

Part VI develops Kalman's matrix rank tests, eigenvector PBH criteria, the four-subspace **Kalman Canonical Decomposition**, and the operational conditions of **stabilizability** and **detectability**.

### Running Example

Across Chapters 20–23, we examine a coupled 3-state LTI system ($\mathbf{A} \in \mathbb{R}^{3\times 3}$) whose third eigenmode $\lambda_3 = -1$ decouples from either input matrix $\mathbf{B}$ or output matrix $\mathbf{C}$:

$$\dot{\mathbf{x}}(t) = \begin{bmatrix} 0 & 1 & 0 \\ -2 & -3 & 1 \\ 0 & 0 & -1 \end{bmatrix}\mathbf{x}(t) + \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}u(t)$$

Chapter 20 tests controllability rank $\operatorname{rank}(\mathcal{R}) = 2 < 3$, Chapter 21 dualizes the test to observability $\operatorname{rank}(\mathcal{O})$, Chapter 22 transforms coordinates to isolate the controllable/observable blocks, and Chapter 23 checks whether the decoupled mode is naturally stable.

### Real-World Applications

- **Actuator Fault Tolerance:** Recomputing $\operatorname{rank}(\mathcal{R})$ after a rotor failure shows whether remaining actuators retain full attitude and altitude control authority.
- **Hidden State Estimation:** Proving full observability of coupled gyro-bias states guarantees that sensor fusion filters can estimate drift without a dedicated bias sensor.
