## Introduction

Chapters 12–15 checked whether *internal states* decay under zero input. In day-to-day testing, however, an engineer only sees external terminals: feed a bounded voltage or force command into a black box and check whether the measured output stays bounded. That external input-output guarantee is **BIBO stability**.

Crucially, internal and external stability are **not always the same thing**: an unstable internal motor current or structural vibration can grow silently without showing up in the output if a pole-zero cancellation blinds the sensor. This chapter clarifies exact time- and $s$-domain BIBO criteria and teaches you never to trust an input-output transfer function blindly without verifying minimality.

<Divider label="1 · Example" />

Consider two systems that show why internal Lyapunov stability and external **BIBO stability** differ:

1. **Hidden Unstable Mode:** Take the diagonal state-space realization:

   $$
   \mathbf{A} = \begin{bmatrix} -2 & 0 \\ 0 & 1 \end{bmatrix}, \quad \mathbf{B} = \begin{bmatrix} 1 \\ 0 \end{bmatrix}, \quad \mathbf{C} = \begin{bmatrix} 3 & 5 \end{bmatrix}, \quad D = 0
   $$

   The eigenvalues of $\mathbf{A}$ are $\lambda_1 = -2$ and $\lambda_2 = +1 > 0$. Because $\lambda_2 > 0$, the system is **internally unstable**: even with $u(t) \equiv 0$, any tiny initial perturbation $x_2(0) \neq 0$ grows exponentially as $x_2(t) = x_2(0)e^t \to \infty$. However, computing the input-output transfer function via the state resolvent $(s\mathbf{I} - \mathbf{A})^{-1}$ gives:

   $$
   W(s) = \mathbf{C}(s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B} = \begin{bmatrix} 3 & 5 \end{bmatrix} \begin{bmatrix} (s+2)^{-1} & 0 \\ 0 & (s-1)^{-1} \end{bmatrix} \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \frac{3}{s + 2}
   $$

   Because $\mathbf{B} = [1, 0]^T$ multiplies the second column by zero, the unstable mode $(s - 1)^{-1}$ cancels completely from $W(s)$. Starting from rest ($\mathbf{x}(0) = \mathbf{0}$), $x_2(t)$ stays identically zero and every bounded input produces a bounded output governed by the single LHP pole $p_1 = -2$ (**BIBO stable**).

2. **Frictionless Integrator ($W(s) = 1/s$):** Its impulse response is the unit step $w(t) = 1(t)$. Under zero input ($\dot{x} = 0$), the state stays constant at $x(t) = x(0)$, so the system is **internally simply stable**. Yet applying a bounded unit step input $u(t) = 1(t)$ produces an unbounded ramp $y(t) = \int_0^t 1 \cdot 1\,d\tau = t \to \infty$, so an integrator is **not BIBO stable**.

### External Boundedness Definition

While [Lyapunov Internal State Stability](/dynamic-courses/systems-theory/04-stability-routh/02-lyapunov-spectral-internal-stability/) examines internal states $\mathbf{x}(t)$ under zero input, **Bounded-Input Bounded-Output (BIBO) stability** is a purely **external (input-output) property** evaluated from rest ($\mathbf{x}(0) = \mathbf{0}$). Setting $\mathbf{x}(0) = \mathbf{0}$ isolates the forced response $y(t) = \int_0^t w(\tau) u(t - \tau)\,d\tau$ from initial-condition transients. A continuous-time LTI system with impulse response $w(t)$ and transfer function $W(s)$ is **BIBO stable** if and only if every bounded input yields a bounded output:

$$\forall u(t) \;:\; \sup_{t \ge 0} |u(t)| \le M_u < \infty \implies \sup_{t \ge 0} |y(t)| \le M_y < \infty$$

for finite constants $M_u, M_y > 0$.

### Time-Domain and Frequency Criteria

From the convolution integral $y(t) = \int_0^t w(\tau) u(t - \tau)\,d\tau$, applying the triangle inequality whenever $|u(t)| \le M_u$ gives:

$$|y(t)| \le \int_0^t |w(\tau)|\,|u(t - \tau)|\,d\tau \le M_u \int_0^t |w(\tau)|\,d\tau \le M_u \int_0^\infty |w(\tau)|\,d\tau$$

Thus **absolute integrability** of the impulse response ($L_1$ norm) is sufficient to guarantee $|y(t)| \le M_u \|w\|_1 < \infty$:

$$\boxed{\|w\|_1 = \int_0^\infty |w(t)| \, dt < \infty}$$

To prove necessity, suppose $\|w\|_1 = \infty$. For any chosen horizon $T > 0$, construct the unit-bounded adversarial input $u_T(t) = \operatorname{sgn}(w(T - t))$ for $0 \le t \le T$ (so $|u_T(t)| \le 1$). At time $t = T$, the output becomes $y(T) = \int_0^T w(\tau)\operatorname{sgn}(w(\tau))\,d\tau = \int_0^T |w(\tau)|\,d\tau$, which grows without bound as $T \to \infty$.

In the Laplace domain, reduce a rational transfer function $W(s) = N(s)/D(s)$ to coprime form (canceling any common factors between numerator and denominator). Partial fraction expansion decomposes $w(t)$ into modes $t^k e^{p_k t}$ for each pole $p_k$. When $\operatorname{Re}(p_k) < 0$, exponential decay tames any polynomial factor ($\int_0^\infty t^k e^{-|\sigma_k|t}\,dt = \frac{k!}{|\sigma_k|^{k+1}} < \infty$). By contrast, any pole on the imaginary axis ($\operatorname{Re}(p_k) = 0$, such as $1(t)$ or $\cos(\omega_0 t)$) or in the RHP ($\operatorname{Re}(p_k) > 0$) has an infinite $L_1$ integral. Therefore, a rational LTI system is BIBO stable **if and only if all poles of reduced $W(s)$ lie strictly in the open left-half plane**:

$$\boxed{\operatorname{Re}(p_k) < 0 \quad \forall k}$$

### Internal vs. BIBO Equivalence

Because $W(s) = \mathbf{C}(s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B} + \mathbf{D} = \frac{\mathbf{C}\operatorname{adj}(s\mathbf{I} - \mathbf{A})\mathbf{B}}{\det(s\mathbf{I} - \mathbf{A})} + \mathbf{D}$, every pole of $W(s)$ must be a root of $\det(s\mathbf{I} - \mathbf{A}) = 0$, unless a factor cancels with the numerator. Hence the poles of $W(s)$ are always a **subset** of the eigenvalues of $\mathbf{A}$:

1. **Internal Asymptotic Stability $\implies$ BIBO Stability (Always True):** If every eigenvalue of $\mathbf{A}$ satisfies $\operatorname{Re}(\lambda_i) < 0$, then every pole of $W(s)$—being a subset of $\sigma(\mathbf{A})$—must also satisfy $\operatorname{Re}(p_k) < 0$.
2. **BIBO Stability $\not\implies$ Internal Asymptotic Stability (In General):** An unstable eigenvalue ($\operatorname{Re}(\lambda_i) \ge 0$) can cancel out of $W(s)$ if that mode is either **uncontrollable** (cannot be excited by $\mathbf{B}$) or **unobservable** (cannot be seen by $\mathbf{C}$), leaving $W(s)$ BIBO stable while internal states diverge.
3. **Minimality Equivalence:** Internal asymptotic stability is equivalent to BIBO stability **if and only if** the state-space realization $(\mathbf{A}, \mathbf{B}, \mathbf{C})$ is **minimal** (both completely controllable and completely observable), because minimality guarantees zero pole-zero cancellations.

<Callout type="bridge" title="SDU Robotics Bridge: AGV Velocity vs. Position Loops">

A DC-motor velocity loop $G_v(s) = \frac{K_m}{\tau_m s + 1}$ ($\tau_m > 0$) has a single LHP pole and is both internally and BIBO stable. <Divider label="3 · Summary" />

| Stability Property | Spectral / $s$-Domain Condition | Integrator $W(s) = 1/s$ | Hidden RHP Mode |
| :--- | :--- | :--- | :--- |
| **Internal Asymptotic** | All $\operatorname{Re}(\lambda_i(\mathbf{A})) < 0$ | Fails | Fails |
| **Simple Lyapunov** | $\operatorname{Re}(\lambda_i) \le 0$, $m_g = m_a$ on $j\omega$-axis | Holds | Fails |
| **BIBO Stability** | $\lVert w\rVert_1 < \infty$ ($\operatorname{Re}(p_k) < 0$ on reduced $W(s)$) | Fails | May hold (non-minimal) |

### Verification Procedure

1. **From $w(t)$:** Evaluate $\|w\|_1 = \int_0^\infty |w(t)|\,dt$; finite implies BIBO stable, infinite implies BIBO unstable.
2. **From $W(s)$:** Reduce $W(s) = N(s)/D(s)$ to coprime form and verify all poles satisfy $\operatorname{Re}(p_k) < 0$ (no $j\omega$-axis or RHP poles).
3. **From $(\mathbf{A}, \mathbf{B}, \mathbf{C})$:** Compare $\sigma(\mathbf{A})$ against the poles of $W(s) = \mathbf{C}(s\mathbf{I}-\mathbf{A})^{-1}\mathbf{B} + \mathbf{D}$; any missing eigenvalue is an uncontrollable or unobservable hidden mode.

### Key Proofs

- **Sufficiency & Necessity of $\|w\|_1 < \infty$:** $|y(t)| \le M_u \|w\|_1$ proves sufficiency, while $u(t) = \operatorname{sgn}(w(T - t))$ yields $y(T) = \int_0^T |w(\tau)|\,d\tau \to \infty$ when $\|w\|_1 = \infty$.
- **Poles vs. Eigenvalues:** $\operatorname{poles}(W(s)) \subseteq \sigma(\mathbf{A})$, with equality holding across all modes when $(\mathbf{A}, \mathbf{B}, \mathbf{C})$ is minimal.

<Callout type="warning" title="Common Mistakes">

1. **Simple Stability $\neq$ BIBO Stability:** An integrator $1/s$ or undamped oscillator $1/(s^2 + \omega_0^2)$ is simply stable under zero input, **never** BIBO stable.
2. **Ignoring Hidden Modes:** Checking only $W(s)$ misses unstable uncontrollable or unobservable internal states; always inspect $\sigma(\mathbf{A})$ when a state-space model is given.
3. **Unreduced Transfer Functions:** Cancel common factors in $W(s)$ only to test *external* BIBO behavior, never to falsely declare a non-minimal loop internally stable.

</Callout>

Consider two continuous-time LTI systems with impulse responses:

1. $w_1(t) = 5 e^{-2t} \cdot 1(t)$
2. $w_2(t) = 3 \cdot 1(t)$

Evaluate the $L_1$ norm $\|w\|_1 = \int_0^\infty |w(t)| \, dt$ for each system, determine which system is BIBO stable, and verify your conclusion from the poles of $W_1(s)$ and $W_2(s)$.

  options={[

    "No, $\\int_0^\\infty |3|\\,dt$ diverges to $\\infty$"

<details className="dc-solution">
<summary>Reveal Worked Solution</summary>

1. For $w_1(t) = 5 e^{-2t} \cdot 1(t)$:
   $$\|w_1\|_1 = \int_0^\infty |5 e^{-2t}| \, dt = 5 \left[ -\frac{1}{2} e^{-2t} \right]_0^\infty = 5 \left( 0 - \left(-\frac{1}{2}\right) \right) = \frac{5}{2} = 2.5 < \infty$$
   Since $\|w_1\|_1 < \infty$, the system is **BIBO stable**. Its Laplace transform $W_1(s) = \frac{5}{s+2}$ has pole $p = -2$ strictly in the open LHP.
2. For $w_2(t) = 3 \cdot 1(t)$:
   $$\|w_2\|_1 = \int_0^\infty |3| \, dt = \lim_{T \to \infty} 3T = +\infty$$
   The integral diverges, so the system is **not BIBO stable**. Its transfer function $W_2(s) = \frac{3}{s}$ has its pole at $s = 0$, failing $\operatorname{Re}(p) < 0$.

</details>

</Exercise>

<Exercise client:load id="ex-16-2" title="Exercise 16.2 — Uncontrollable RHP Mode" level="Exam Standard">

A continuous-time system has state-space realization:

$$\mathbf{A} = \begin{bmatrix} -3 & 0 \\ 0 & 2 \end{bmatrix}, \quad \mathbf{B} = \begin{bmatrix} 1 \\ 0 \end{bmatrix}, \quad \mathbf{C} = \begin{bmatrix} 2 & 4 \end{bmatrix}, \quad D = 0$$

1. Compute the eigenvalues of $\mathbf{A}$ and classify the internal Lyapunov stability of $\mathbf{x}_e = \mathbf{0}$.
2. Compute the transfer function $W(s) = \mathbf{C}(s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B}$.
3. Find the poles of $W(s)$ and determine whether the system is BIBO stable.
4. Explain why the input-output response stays bounded despite $\mathbf{A}$ having an RHP eigenvalue, and identify whether that eigenvalue is uncontrollable or unobservable.

  client:load
  mode="choice"
  prompt="Why does the RHP eigenvalue $\lambda_2 = +2$ disappear from $W(s) = \frac{2}{s+3}$?"
  options={[

    "Because $\\lambda_2 = +2$ is completely uncontrollable through $\\mathbf{B} = [1, 0]^T$",
    "Because $D = 0$ cancels the unstable pole"
  ]}
  correctIndex={1}
  explanation="The controllability matrix $\mathcal{M}_c = [\mathbf{B} \;\; \mathbf{A}\mathbf{B}] = \begin{bmatrix}1 & -3 \\ 0 & 0\end{bmatrix}$ has rank $1 < 2$: input $u(t)$ never drives $x_2$, making $\lambda_2 = +2$ uncontrollable while $W(s)$ remains BIBO stable."
/>

<details className="dc-solution">
<summary>Reveal Worked Solution</summary>

1. Eigenvalues of diagonal matrix $\mathbf{A} = \begin{bmatrix} -3 & 0 \\ 0 & 2 \end{bmatrix}$ are $\lambda_1 = -3$ and $\lambda_2 = +2$. Because $\operatorname{Re}(\lambda_2) > 0$, $\mathbf{x}_e = \mathbf{0}$ is **internally unstable**.
2. Transfer function calculation:
   $$W(s) = \begin{bmatrix} 2 & 4 \end{bmatrix} \begin{bmatrix} \frac{1}{s+3} & 0 \\ 0 & \frac{1}{s-2} \end{bmatrix} \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 2 & 4 \end{bmatrix} \begin{bmatrix} \frac{1}{s+3} \\ 0 \end{bmatrix} = \frac{2}{s+3}$$
3. Poles of $W(s)$ and BIBO stability:
   The sole pole $p = -3$ satisfies $\operatorname{Re}(p) < 0$, so the system is **BIBO stable** ($|y(t)| \le \frac{2}{3}M_u$ from zero initial state).
4. Resolution of the paradox:
   The realization is non-minimal with controllability matrix $\mathcal{M}_c = \begin{bmatrix} \mathbf{B} & \mathbf{A}\mathbf{B} \end{bmatrix} = \begin{bmatrix} 1 & -3 \\ 0 & 0 \end{bmatrix}$ ($\operatorname{rank}(\mathcal{M}_c) = 1 < 2$). State $x_2$ evolves as $\dot{x}_2 = 2x_2 + 0\cdot u$, so $\lambda_2 = +2$ is **completely uncontrollable** and cancels from $W(s)$ while diverging internally whenever $x_2(0) \neq 0$.

</details>

</Exercise>
