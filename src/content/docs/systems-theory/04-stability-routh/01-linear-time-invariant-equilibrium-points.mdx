## Concept and Definition of Equilibrium State
### Physical Intuition: The Stationary Condition
In physical systems, dynamic variables continuously evolve over time: an aircraft pitches and rolls, an electrical capacitor charges and discharges, and a robotic arm sweeps through space. However, under certain conditions, a system settles into a state of rest where all physical forces, currents, and rates of change balance out to zero.

An **equilibrium state** (also called an *operating point*, *quiescent state*, or *trim condition*) represents a permanent stationary configuration:
> If a system's internal energy storage elements are initialized at an equilibrium state, and if the external input applied to the system remains held at a constant value, the system state remains frozen at that point for all subsequent time.

Consider familiar physical systems:
* A mass suspended from a mechanical spring reaches equilibrium when the downward gravitational force exactly matches the upward elastic restoring force.
* A direct-current motor reaches angular velocity equilibrium when the electrical electromagnetic torque generated by the winding current exactly balances the viscous friction torque of the mechanical load.
* An autonomous drone reaches hover equilibrium when the aerodynamic thrust generated by its propellers equals the total gravitational weight of the vehicle.

### Formal Mathematical Definition
We formalize this stationary concept for the general continuous-time linear time-invariant (LTI) state-space model:
$$\dot{\mathbf{x}}(t) = \mathbf{A}\mathbf{x}(t) + \mathbf{B}\mathbf{u}(t), \quad \mathbf{x}(t) \in \mathbb{R}^n, \; \mathbf{u}(t) \in \mathbb{R}^m$$
$$\mathbf{y}(t) = \mathbf{C}\mathbf{x}(t) + \mathbf{D}\mathbf{u}(t), \quad \mathbf{y}(t) \in \mathbb{R}^p$$

A state vector $\mathbf{x}_e \in \mathbb{R}^n$ is defined as an **equilibrium point** corresponding to a constant external input $\mathbf{u}(t) \equiv \mathbf{u}_0 \in \mathbb{R}^m$ if, whenever initialized at $\mathbf{x}(0) = \mathbf{x}_e$, the state remains constant for all $t \ge 0$:
$$\mathbf{x}(t) \equiv \mathbf{x}_e \quad \forall t \ge 0$$

Because the state vector $\mathbf{x}(t)$ is constant for all time, its time derivative—the velocity vector along the state trajectory—must vanish identically:
$$\dot{\mathbf{x}}(t) = \frac{d}{dt}(\mathbf{x}_e) = \mathbf{0} \quad \forall t \ge 0$$

Conversely, if $\dot{\mathbf{x}}(t) = \mathbf{0}$ at an instant when the state is $\mathbf{x}_e$ under constant input $\mathbf{u}_0$, then by the fundamental uniqueness theorem for linear ordinary differential equations, the trajectory cannot move away from $\mathbf{x}_e$, ensuring $\mathbf{x}(t) \equiv \mathbf{x}_e$ for all $t \ge 0$.

### Operational LTI Criterion
To determine the equilibrium state algebraically, we substitute the condition $\dot{\mathbf{x}}(t) = \mathbf{0}$ directly into the state equation the equation above evaluated at $\mathbf{x}(t) = \mathbf{x}_e$ and $\mathbf{u}(t) = \mathbf{u}_0$:
$$\mathbf{0} = \mathbf{A}\mathbf{x}_e + \mathbf{B}\mathbf{u}_0$$

Rearranging this yields the fundamental linear algebraic system governing all LTI equilibria:
$$\boxed{\mathbf{A}\mathbf{x}_e = -\mathbf{B}\mathbf{u}_0}$$

The corresponding static equilibrium output is evaluated by substituting $\mathbf{x}_e$ and $\mathbf{u}_0$ into the output equation the equation above:
$$\mathbf{y}_e = \mathbf{C}\mathbf{x}_e + \mathbf{D}\mathbf{u}_0$$

For unforced systems ($\mathbf{u}_0 = \mathbf{0}$), the algebraic condition simplifies to the homogeneous equation:
$$\mathbf{A}\mathbf{x}_e = \mathbf{0}$$
Because $\mathbf{A} \cdot \mathbf{0} = \mathbf{0}$ for every matrix $\mathbf{A}$, the origin of the state space $\mathbf{x}_e = \mathbf{0}$ is **always** an equilibrium point for any unforced continuous-time linear system.

## Algebraic Solvability via Rouché-Capelli Theorem
### Step-by-Step Solvability Analysis
The algebraic equation $\mathbf{A}\mathbf{x}_e = -\mathbf{B}\mathbf{u}_0$ represents a system of $n$ linear algebraic equations in $n$ unknowns (the coordinates of $\mathbf{x}_e$). The existence, uniqueness, or multiplicity of equilibrium points is completely governed by the rank of the dynamic matrix $\mathbf{A}$ and the augmented matrix $[\mathbf{A} \;|\; -\mathbf{B}\mathbf{u}_0]$ via the Rouché-Capelli theorem.

### Case 1: Non-Singular System Matrix ($\det(\mathbf{A}) \neq 0$)
When $\det(\mathbf{A}) \neq 0$, the matrix $\mathbf{A}$ has full rank $\operatorname{rank}(\mathbf{A}) = n$. Zero is not an eigenvalue of $\mathbf{A}$. The matrix inverse $\mathbf{A}^{-1}$ exists and is unique.

Under this condition:
1. There exists **one and only one unique isolated equilibrium state**:
   $$\boxed{\mathbf{x}_e = -\mathbf{A}^{-1}\mathbf{B}\mathbf{u}_0}$$
2. The corresponding steady-state output vector is:
   $$\mathbf{y}_e = (-\mathbf{C}\mathbf{A}^{-1}\mathbf{B} + \mathbf{D})\mathbf{u}_0 = \mathbf{W}(0)\mathbf{u}_0$$
   where $\mathbf{W}(0) = -\mathbf{C}\mathbf{A}^{-1}\mathbf{B} + \mathbf{D}$ is the static transfer function (DC gain) matrix of the system.
3. In the unforced case ($\mathbf{u}_0 = \mathbf{0}$), the origin $\mathbf{x}_e = \mathbf{0}$ is the strictly unique equilibrium point.

### Case 2: Singular System Matrix ($\det(\mathbf{A}) = 0$)
When $\det(\mathbf{A}) = 0$, the matrix $\mathbf{A}$ has rank $r < n$. The matrix possesses at least one eigenvalue at the origin ($\lambda = 0$) with geometric multiplicity $m_g(0) = n - r \ge 1$. The null space (kernel) $\ker(\mathbf{A}) = \{\mathbf{v} \in \mathbb{R}^n \;|\; \mathbf{A}\mathbf{v} = \mathbf{0}\}$ is non-trivial and has dimension $n - r$.

Applying the Rouché-Capelli theorem to $\mathbf{A}\mathbf{x}_e = -\mathbf{B}\mathbf{u}_0$, two physically distinct situations occur:

1. **Incompatible Input ($-\mathbf{B}\mathbf{u}_0 \notin \operatorname{Im}(\mathbf{A})$):**
   $$\operatorname{rank}([\mathbf{A} \;|\; -\mathbf{B}\mathbf{u}_0]) = r + 1 > \operatorname{rank}(\mathbf{A}) = r$$
   **Zero equilibrium states exist.** The input vector excites an internal integrator mode that is not balanced by any restoring feedback. As a result, the state trajectory ramps indefinitely toward infinity without ever reaching a stationary state. A direct physical example is applying a constant net force to an unconstrained mass: the mass accelerates continuously, so its velocity never settles.

2. **Compatible Input ($-\mathbf{B}\mathbf{u}_0 \in \operatorname{Im}(\mathbf{A})$):**
   $$\operatorname{rank}([\mathbf{A} \;|\; -\mathbf{B}\mathbf{u}_0]) = \operatorname{rank}(\mathbf{A}) = r$$
   There exist **infinitely many equilibrium states**, forming an affine linear manifold:
   $$\boxed{\mathbf{x}_e = \mathbf{x}_{e,\text{part}} + \ker(\mathbf{A}) = \mathbf{x}_{e,\text{part}} + \sum_{k=1}^{n-r} \alpha_k \mathbf{v}_k, \quad \alpha_k \in \mathbb{R}}$$
   where $\mathbf{x}_{e,\text{part}}$ is any particular solution to $\mathbf{A}\mathbf{x}_e = -\mathbf{B}\mathbf{u}_0$, and $\{\mathbf{v}_1, \dots, \mathbf{v}_{n-r}\}$ is a basis for the null space $\ker(\mathbf{A})$.

For an unforced system ($\mathbf{u}_0 = \mathbf{0}$), compatibility is always satisfied because $-\mathbf{B}(\mathbf{0}) = \mathbf{0} \in \operatorname{Im}(\mathbf{A})$. The set of equilibrium states is the entire subspace $\ker(\mathbf{A})$.

## Perturbation Dynamics and Coordinate Translation
### Physical Motivation: Control Around Operating Points
Industrial systems rarely operate at the zero state. A chemical reactor operates at an elevated temperature and pressure, an aircraft cruises at a non-zero altitude and airspeed, and a magnetic levitation system suspends a ball at an equilibrium height against gravity.

When analyzing the stability of an equilibrium operating point $(\mathbf{x}_e, \mathbf{u}_0)$, or when designing a feedback controller to suppress transient disturbances, we study how the system responds to small deviations from that equilibrium.

### Derivation of Perturbation State Equations
We define the **perturbation state vector** $\mathbf{z}(t)$ and **perturbation input vector** $\mathbf{v}(t)$ as the deviations from equilibrium:
$$\mathbf{z}(t) = \mathbf{x}(t) - \mathbf{x}_e, \quad \mathbf{v}(t) = \mathbf{u}(t) - \mathbf{u}_0$$

Differentiating $\mathbf{z}(t)$ with respect to time:
$$\dot{\mathbf{z}}(t) = \dot{\mathbf{x}}(t) - \dot{\mathbf{x}}_e$$

Because $\mathbf{x}_e$ is a constant vector, its time derivative is zero ($\dot{\mathbf{x}}_e = \mathbf{0}$). Substituting the original system dynamics $\dot{\mathbf{x}} = \mathbf{A}\mathbf{x} + \mathbf{B}\mathbf{u}$:
$$\dot{\mathbf{z}}(t) = \mathbf{A}\mathbf{x}(t) + \mathbf{B}\mathbf{u}(t)$$

Expressing the total state and input in terms of deviations, $\mathbf{x}(t) = \mathbf{x}_e + \mathbf{z}(t)$ and $\mathbf{u}(t) = \mathbf{u}_0 + \mathbf{v}(t)$:
$$\dot{\mathbf{z}}(t) = \mathbf{A}(\mathbf{x}_e + \mathbf{z}(t)) + \mathbf{B}(\mathbf{u}_0 + \mathbf{v}(t))$$
$$\dot{\mathbf{z}}(t) = \underbrace{(\mathbf{A}\mathbf{x}_e + \mathbf{B}\mathbf{u}_0)}_{= \mathbf{0} \text{ (by equilibrium condition)}} + \mathbf{A}\mathbf{z}(t) + \mathbf{B}\mathbf{v}(t)$$

$$\boxed{\dot{\mathbf{z}}(t) = \mathbf{A}\mathbf{z}(t) + \mathbf{B}\mathbf{v}(t)}$$

Similarly, for the output perturbation $\mathbf{w}(t) = \mathbf{y}(t) - \mathbf{y}_e$:
$$\mathbf{w}(t) = \mathbf{C}\mathbf{z}(t) + \mathbf{D}\mathbf{v}(t)$$

### The Equivalence Invariant
Notice that the deviation system the equation above is governed by the exact same dynamic matrix $\mathbf{A}$ and input matrix $\mathbf{B}$ as the original model. Furthermore, when the original system is exactly at equilibrium ($\mathbf{x} = \mathbf{x}_e$), the deviation state is at the origin ($\mathbf{z} = \mathbf{0}$).

This yields a central conclusion:
> In linear systems, analyzing whether an equilibrium state $\mathbf{x}_e$ is stable or unstable is mathematically equivalent to analyzing whether the origin $\mathbf{z} = \mathbf{0}$ of the perturbation dynamics $\dot{\mathbf{z}} = \mathbf{A}\mathbf{z}$ is stable or unstable.

Because the matrix $\mathbf{A}$ is invariant under this coordinate translation, internal stability is an intrinsic property of the system matrix $\mathbf{A}$ itself, completely independent of which specific equilibrium point $\mathbf{x}_e$ is selected. This allows us to focus our stability analysis entirely on the origin $\mathbf{x}_e = \mathbf{0}$ of autonomous systems, as established in Chapter 12.

<Callout type="tip" title="Robotics Application: Mobile Robots and Drone Hover Trim">

1. **Differential-Drive Heading:**
   A mobile robot with heading angle $\theta$ and angular velocity $\omega$ satisfies:
   $$\dot{\theta}(t) = \omega(t), \quad \dot{\omega}(t) = -\frac{d_m}{J}\omega(t) + \frac{k_t}{J} u(t)$$
   In state space with $\mathbf{x} = [\theta, \; \omega]^T$, the dynamic matrix is singular ($\det(\mathbf{A}) = 0$). For zero input torque $u_0 = 0$, the set of equilibrium points is the line $\mathbf{x}_e = [\theta_e, \; 0]^T$ for any arbitrary heading $\theta_e \in [-\pi, \pi]$.
2. **Quadrotor Vertical Hover:**
   A quadrotor of mass $m$ has vertical dynamics $\dot{z} = v_z$ and $\dot{v}_z = -g + \frac{1}{m}T(t)$. Hover equilibrium requires $-g + \frac{1}{m}T_0 = 0 \implies T_0 = mg$. When thrust matches gravity, any altitude $z_e$ forms a valid equilibrium state.

<Exercise client:load id="ex-11-1" title="Exercise 11.1" level="LEVEL 1: WARM-UP DRILL">

Given the continuous-time LTI system:
$$\dot{\mathbf{x}}(t) = \mathbf{A}\mathbf{x}(t) + \mathbf{B}u(t)$$
with parameters:
$$\mathbf{A} = \begin{bmatrix} -2 & 1 \\ 1 & -3 \end{bmatrix}, \quad \mathbf{B} = \begin{bmatrix} 1 \\ 4 \end{bmatrix}, \quad u_0 = 5$$
1. Compute the determinant $\det(\mathbf{A})$ and show that $\mathbf{A}$ is non-singular.
2. Determine the matrix inverse $\mathbf{A}^{-1}$.
3. Calculate the unique equilibrium state vector $\mathbf{x}_e = -\mathbf{A}^{-1}\mathbf{B} u_0$.
4. Verify by direct matrix multiplication that $\mathbf{A}\mathbf{x}_e + \mathbf{B} u_0 = \mathbf{0}$.

<details className="dc-solution">
<summary>Reveal Worked Solution</summary>

1. Determinant and non-singularity:
   $$\det(\mathbf{A}) = \det\begin{bmatrix} -2 & 1 \\ 1 & -3 \end{bmatrix} = (-2)(-3) - (1)(1) = 6 - 1 = 5 \neq 0$$
   Since $\det(\mathbf{A}) = 5 \neq 0$, the matrix has full rank ($\operatorname{rank}(\mathbf{A}) = 2$) and is strictly non-singular.
2. Matrix inversion:
   $$\mathbf{A}^{-1} = \frac{1}{\det(\mathbf{A})} \begin{bmatrix} -3 & -1 \\ -1 & -2 \end{bmatrix} = \frac{1}{5} \begin{bmatrix} -3 & -1 \\ -1 & -2 \end{bmatrix}$$
3. Equilibrium state computation:
   $$\mathbf{B} u_0 = \begin{bmatrix} 1 \\ 4 \end{bmatrix} \cdot 5 = \begin{bmatrix} 5 \\ 20 \end{bmatrix}$$
   $$\mathbf{x}_e = -\mathbf{A}^{-1}\mathbf{B} u_0 = -\frac{1}{5} \begin{bmatrix} -3 & -1 \\ -1 & -2 \end{bmatrix} \begin{bmatrix} 5 \\ 20 \end{bmatrix} = -\frac{1}{5} \begin{bmatrix} -15 - 20 \\ -5 - 40 \end{bmatrix} = -\frac{1}{5} \begin{bmatrix} -35 \\ -45 \end{bmatrix} = \begin{bmatrix} 7 \\ 9 \end{bmatrix}$$
4. Algebraic verification:
   $$\mathbf{A}\mathbf{x}_e + \mathbf{B} u_0 = \begin{bmatrix} -2 & 1 \\ 1 & -3 \end{bmatrix} \begin{bmatrix} 7 \\ 9 \end{bmatrix} + \begin{bmatrix} 5 \\ 20 \end{bmatrix} = \begin{bmatrix} -14 + 9 \\ 7 - 27 \end{bmatrix} + \begin{bmatrix} 5 \\ 20 \end{bmatrix} = \begin{bmatrix} -5 \\ -20 \end{bmatrix} + \begin{bmatrix} 5 \\ 20 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} \quad \checkmark$$

</details>

<Exercise client:load id="ex-11-2" title="Exercise 11.2" level="LEVEL 2: EXAM BENCHMARK">

In a university examination, consider a system with a singular state matrix:
$$\mathbf{A} = \begin{bmatrix} 1 & -2 & 1 \\ 0 & 2 & -4 \\ -1 & 0 & 3 \end{bmatrix}, \quad \mathbf{B}_1 = \begin{bmatrix} 0 \\ 2 \\ -2 \end{bmatrix}, \quad \mathbf{B}_2 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}, \quad u_0 = 1$$
1. Compute $\det(\mathbf{A})$ and determine the rank of $\mathbf{A}$. Compute a basis vector $\mathbf{v}$ spanning the null space $\ker(\mathbf{A})$.
2. Apply the Rouché-Capelli theorem to test solvability for input vector $\mathbf{B}_1 u_0$. Find a particular solution $\mathbf{x}_{e,\text{part}}$ and write the complete parametric family of equilibrium states $\mathbf{x}_e(\alpha)$.
3. Apply the Rouché-Capelli theorem to input vector $\mathbf{B}_2 u_0$. Does an equilibrium state exist? Explain why by inspecting the column space $\operatorname{Im}(\mathbf{A})$.
4. Explain the physical dynamics of the system when excited by a constant input $\mathbf{B}_2 u_0 \notin \operatorname{Im}(\mathbf{A})$.

<details className="dc-solution">
<summary>Reveal Worked Solution</summary>

1. Determinant, rank, and null space:
   $$\det(\mathbf{A}) = 1(6 - 0) - (-2)(0 - 4) + 1(0 - (-2)) = 6 - 8 + 2 = 0$$
   Inspecting the top-left $2 \times 2$ minor:
   $$\det\begin{bmatrix} 1 & -2 \\ 0 & 2 \end{bmatrix} = 2 \neq 0 \implies \operatorname{rank}(\mathbf{A}) = 2$$
   Solving $\mathbf{A}\mathbf{v} = \mathbf{0}$:
   $$\begin{cases} v_1 - 2v_2 + v_3 = 0 \\ 2v_2 - 4v_3 = 0 \implies v_2 = 2v_3 \\ -v_1 + 3v_3 = 0 \implies v_1 = 3v_3 \end{cases}$$
   Choosing $v_3 = 1$ yields the null space basis vector:
   $$\ker(\mathbf{A}) = \operatorname{span}\left\{ \begin{bmatrix} 3 \\ 2 \\ 1 \end{bmatrix} \right\}$$
2. Rouché-Capelli compatibility for $\mathbf{B}_1 u_0$:
   The linear equilibrium system is $\mathbf{A}\mathbf{x}_e = -\mathbf{B}_1 u_0 = \begin{bmatrix} 0 \\ -2 \\ 2 \end{bmatrix}$.
   Forming the augmented matrix:
   $$[\mathbf{A} \mid -\mathbf{B}_1 u_0] = \begin{bmatrix} 1 & -2 & 1 & 0 \\ 0 & 2 & -4 & -2 \\ -1 & 0 & 3 & 2 \end{bmatrix}$$
   Adding Row 1 to Row 3 produces:
   $$\begin{bmatrix} 0 & -2 & 4 & 2 \end{bmatrix} = -1 \times \text{Row 2}$$
   Because Row 3 is a linear combination of Row 1 and Row 2, $\operatorname{rank}[\mathbf{A} \mid -\mathbf{B}_1 u_0] = 2 = \operatorname{rank}(\mathbf{A})$.
   By the Rouché-Capelli theorem, the system is compatible with $\infty^{3-2} = \infty^1$ solutions.
   Finding a particular solution by setting $x_{e3} = 0$:
   * Row 2: $2x_{e2} = -2 \implies x_{e2} = -1$.
   * Row 1: $x_{e1} - 2(-1) = 0 \implies x_{e1} = -2$.
   Particular solution: $\mathbf{x}_{e,\text{part}} = [-2, -1, 0]^T$.
   Complete 1-dimensional manifold of equilibria:
   $$\mathbf{x}_e(\alpha) = \begin{bmatrix} -2 \\ -1 \\ 0 \end{bmatrix} + \alpha \begin{bmatrix} 3 \\ 2 \\ 1 \end{bmatrix}, \quad \alpha \in \mathbb{R}$$
3. Rouché-Capelli compatibility for $\mathbf{B}_2 u_0$:
   The equilibrium system is $\mathbf{A}\mathbf{x}_e = -\mathbf{B}_2 u_0 = \begin{bmatrix} -1 \\ 0 \\ 0 \end{bmatrix}$.
   Augmented matrix:
   $$[\mathbf{A} \mid -\mathbf{B}_2 u_0] = \begin{bmatrix} 1 & -2 & 1 & -1 \\ 0 & 2 & -4 & 0 \\ -1 & 0 & 3 & 0 \end{bmatrix}$$
   Adding Row 1 to Row 3 produces $\begin{bmatrix} 0 & -2 & 4 & -1 \end{bmatrix}$.
   Adding Row 2 produces $\begin{bmatrix} 0 & 0 & 0 & -1 \end{bmatrix} \implies 0 = -1$.
   Consequently, $\operatorname{rank}[\mathbf{A} \mid -\mathbf{B}_2 u_0] = 3 \neq \operatorname{rank}(\mathbf{A}) = 2$.
   By Rouché-Capelli, $-\mathbf{B}_2 u_0 \notin \operatorname{Im}(\mathbf{A})$; **no equilibrium state exists**.
4. Physical consequence:
   When an uncompensated constant input vector $\mathbf{B}_2 u_0 \notin \operatorname{Im}(\mathbf{A})$ acts on a singular system, the input directly projects onto the unconstrained integrator mode. The internal states can never produce a balancing counter-rate ($\dot{\mathbf{x}} \neq \mathbf{0}$); the system undergoes continuous, unbounded drift along the integrator state direction.

</details>
