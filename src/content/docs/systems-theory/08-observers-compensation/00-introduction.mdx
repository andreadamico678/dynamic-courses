## Introduction

Full-state feedback in Part VII assumed all $n$ state variables $x_i(t)$ are directly wired to sensors—rarely true in physical hardware where encoders measure position without clean velocity or internal thermal/motor states. Part VIII reconstructs the unmeasured state online using a **Luenberger State Observer** driven by actuator inputs $\mathbf{u}(t)$ and sensor output innovations $\mathbf{y}(t) - \mathbf{C}\hat{\mathbf{x}}(t)$.

Chapters 27–29 establish autonomous error convergence $\dot{\mathbf{e}} = (\mathbf{A} - \mathbf{L}\mathbf{C})\mathbf{e}$, synthesize the observer gain $\mathbf{L}$ directly via Kalman duality, and prove the **Separation Principle** guaranteeing that feeding $\hat{\mathbf{x}}(t)$ into $\mathbf{u} = -\mathbf{K}\hat{\mathbf{x}}$ preserves both controller and observer eigenvalues independently.

### Running Example

Across Chapters 27–29, we estimate and control an observable servo plant from scalar output $y(t) = \mathbf{C}\mathbf{x}(t)$:

$$\dot{\hat{\mathbf{x}}}(t) = \mathbf{A}\hat{\mathbf{x}}(t) + \mathbf{B}\mathbf{u}(t) + \mathbf{L}\big(\mathbf{y}(t) - \mathbf{C}\hat{\mathbf{x}}(t)\big), \qquad \mathbf{u}(t) = -\mathbf{K}\hat{\mathbf{x}}(t) + \mathbf{v}(t)$$

Chapter 27 derives error matrix $\mathbf{A} - \mathbf{L}\mathbf{C}$ and observer bandwidth rules, Chapter 28 solves $\mathbf{L} = p_o^*(\mathbf{A})\mathcal{O}^{-1}\mathbf{e}_n$ via dual Ackermann synthesis, and Chapter 29 couples $\mathbf{K}$ and $\mathbf{L}$ into one dynamic output compensator $C(s)$.

### Real-World Applications

- **Noise-Free Velocity Estimation:** Luenberger observers fuse position encoders and plant dynamics to estimate clean velocities without finite-difference quantization spikes.
- **Modular Estimation & Control:** The Separation Principle lets flight and robotics stacks decouple state estimation nodes from trajectory controller nodes safely.
