## Introduction

A synchronous **Finite State Machine (FSM)** tracks historical input patterns using a finite set of clocked states $S^t \in \{S_0, S_1, \dots\}$ updated on each active `CLK` edge. In a **Mealy sequence detector**, both the next state $S^{t+1} = \delta(S^t, xy^t)$ and the scalar output $u^t = \lambda(S^t, xy^t)$ depend directly on the present state and the current 2-bit parallel input $xy^t \in \{00, 01, 11, 10\}$, allowing $u^t$ to assert to `1` on the transition arc during the **exact same clock cycle** that the final symbol of a valid sequence arrives.

### Dual-Branch Detector with Repetition and Overlap

Consider Question 1 from the **January 2026 (Variant C1)** examination: design a 2-input Mealy FSM over $xy \in \{00, 01, 11, 10\}$ that asserts $u = 1$ whenever either consecutive sequence is recognized, including partially overlapping sequences:

$$\sigma_A = \{11, (10, \dots, 10), 11, (01, \dots, 01), 00\}, \qquad \sigma_B = \{11, (10, \dots, 10), (01, \dots, 01), 00\}$$

Here $(XY, \dots, XY)$ denotes one or more consecutive occurrences of $XY$, so the shortest accepted sequences are $\{11, 10, 11, 01, 00\}$ and $\{11, 10, 01, 00\}$.

Both branches share the opening prefix $11$ followed by $(10)^+$, fork depending on whether an intermediate $11$ appears (Branch A) or `01` arrives immediately (Branch B), and rejoin inside the final $(01)^+$ loop before terminating on `00`. That structure requires **5 states**:

- **$S_0$ (Reset $\varepsilon$):** No valid prefix matched; awaits initial `11`.
- **$S_1$ (Prefix `11`):** Matched opening `11`. A second consecutive `11` stays in $S_1 / 0$ (restarting the prefix), while `10` advances to $S_2 / 0$.
- **$S_2$ (Loop `11, (10)+`):** At least one `10` matched. Additional `10` inputs self-loop ($S_2 \xrightarrow{10/0} S_2$); `11` branches to $S_3 / 0$ (Branch A); `01` jumps directly to $S_4 / 0$ (Branch B).
- **$S_3$ (Prefix `11, (10)+, 11`):** Intermediate `11` of Branch A matched. Input `01` advances to $S_4 / 0$. What if `10` arrives instead? The recent stream ends in `11, 10`, which matches the exact prefix of $S_2$, so $S_3 \xrightarrow{10/0} S_2$! Similarly, `11` ends in `11`, routing $S_3 \xrightarrow{11/0} S_1$.
- **$S_4$ (Loop `..., (01)+`):** Inside the final `01` repetition loop of either branch (`01` self-loops to $S_4 / 0$). Input `11` restarts prefix $S_1 / 0$, `10` resets to $S_0 / 0$, and terminal input `00` completes the sequence with **$S_0 / 1$** (returning to $S_0$ because `00` cannot start a new `11`-headed sequence).

<Divider label="2 · Theory" />

We start from the Mealy hardware topology that produces same-cycle arc outputs, then formalize the transition rules for repetition loops and Longest Proper Prefix-Suffix (LPS) overlap, and finally establish state-count and branch-merging conditions for single- and multi-branch detectors.

### Mealy Architecture and Zero-Latency Output

A synchronous Mealy machine separates clocked state memory from two combinational logic blocks: the **next-state network** $S^{t+1} = \delta(S^t, xy^t)$ driving the flip-flop inputs, and the **output network** $u^t = \lambda(S^t, xy^t)$ driven by both the state flip-flops and the live input bus $xy^t$.

  <img src="/dynamic-courses/diagrams/computer-architecture/fig-mealy-arch.svg" alt="Block diagram of a synchronous Mealy machine showing direct combinational feedthrough from input xy into output logic lambda." />
  <figcaption>Synchronous Mealy topology: the direct combinational path from $xy$ into $\lambda$ enables same-cycle ($0$-latency) output assertion.</figcaption>
</figure>

Because $xy^t$ feeds straight into $\lambda$, outputs belong to **transition arcs** (`xy / u`) rather than state circles. As soon as the final symbol of a target sequence stabilizes on $xy^t$, $u^t$ rises to `1` within that same clock cycle—before the next clock edge latches $S^{t+1}$.

### Repetition Loops and Overlap Rules

Exam sequence specifications combine three structural patterns that follow strict mechanical rules:

1. **Mandatory Repetition $(XY, \dots, XY) \equiv (XY)^+$:** At least one $XY$ is required. You must use a **forward arc** into a dedicated loop state on the first $XY$, then place a **self-loop** $S_k \xrightarrow{XY/0} S_k$ on that loop state to absorb any additional consecutive $XY$ symbols. Never place the self-loop on the preceding state, or zero occurrences of $XY$ would be accepted!
2. **Longest Proper Prefix-Suffix (LPS) Mismatch Recovery:** When an unexpected symbol $xy$ arrives in state $S_i$, form the candidate history string $T = \text{History}(S_i) + [xy]$ and test suffixes of $T$ from longest to shortest. Route the arc ($u = 0$) to the state whose canonical prefix matches the longest valid suffix of $T$ (or to $S_0$ if none match).
3. **Overlapping Terminal Return:** When the final symbol $xy$ completes a target sequence ($u = 1$), apply the exact same LPS suffix test to $W = \text{History}(S_i) + [xy]$. If the ending symbol(s) of the completed sequence also form a valid opening prefix (for example, a sequence both starting and ending with `00`), route the `u = 1` arc directly to that prefix state ($S_1$) rather than $S_0$.

### State Count and Branch Merging

Three structural sizing rules govern how many states and table entries a Mealy detector requires:

1. **Fixed-Length State Count:** Recognizing a single fixed sequence of length $L$ symbols requires exactly **$L$ states** ($S_0$ for $\varepsilon$ through $S_{L-1}$ for the $(L-1)$-symbol prefix). No $(L+1)$-th recognition state is needed because the $L$-th symbol asserts $u = 1$ directly on the outgoing arc from $S_{L-1}$ while transitioning straight to the LPS overlap target.
2. **Branch Merging Criterion:** In a multi-branch specification, branches share a common opening trunk for identical leading symbols, and may merge into a **shared closing loop state only if** their remaining required symbols and terminal recognition outputs are identical. If two branches end with the same `(01)+` repetition block but one recognizes on `10` while the other recognizes on `00`, their closing loop states must remain **separate** so each branch asserts $u = 1$ on its own terminal symbol.
3. **Cross-Branch LPS and Table Completeness:** When evaluating the LPS suffix of $\text{History}(S_i) + [xy]$ on any mismatch or completion arc, test suffixes against **all** defined state prefixes across **all** branches (allowing a mismatch in Branch A to land inside Branch B's prefix). For an $m$-bit parallel input bus ($2^m$ input symbols, so $2^2 = 4$ for $xy \in \{00, 01, 11, 10\}$), a complete state table must populate all $2^m \times \lvert S \rvert = 4 \times \lvert S \rvert$ compound entries $S^{t+1} / u$.

<Callout type="tip" title="Practical Hardware Perspective">

In embedded robotics communication links—such as **SBUS** (`0x0F` header byte) or **MAVLink** packet framing on drone UART peripherals—hardware Mealy recognizers flag start-of-frame delimiters at line rate with zero CPU interrupt overhead. However, because asynchronous noise on input pins $xy$ propagates straight through $\lambda$ as combinational **glitches**, Mealy outputs should never drive asynchronous reset or clock pins directly without an output flip-flop.

</Callout>

| Transition Case in State $S_i$ | Next-State Rule ($S^{t+1}$) | Output ($u$) |
| :--- | :--- | :---: |
| **Forward Mandatory Symbol** | Advance to next prefix state $S_{\text{next}}$ | $0$ |
| **Repeating Symbol in Active $(XY)^+$ State** | Self-loop to current state $S_i$ | $0$ |
| **Terminal Symbol Completing Sequence** | Longest valid prefix matching a proper suffix of $\text{History}(S_i) + [xy]$ | **$1$** |
| **Unexpected / Divergent Symbol** | Longest valid prefix matching a proper suffix of $\text{History}(S_i) + [xy]$ (else $S_0$) | $0$ |

### Synthesis Procedure

1. **Parse Minimal Paths and Trunk:** Replace every $(XY, \dots, XY)$ with one $XY$ to list each branch's shortest accepted string; merge shared opening symbols and merge closing loops only if their terminal exit symbols match.
2. **Allocate Prefix States:** Assign $S_0$ to $\varepsilon$, allocate one state per mandatory step ($L$ states for a fixed length-$L$ pattern), and place an entry arc plus self-loop ($XY / 0$) on every $(XY)^+$ state.
3. **Resolve All Transitions via LPS:** For every state and all 4 inputs, test $\text{History}(S_i) + [xy]$ against all branch prefixes for both mismatches ($u = 0$) and terminal completions ($u = 1$).
4. **Tabulate in Gray Order:** Populate all $4 \times \lvert S \rvert$ cells (`NextState / Output`) across columns `00, 01, 11, 10` and verify $u = 1$ appears solely on terminal arcs.

<Callout type="warning" title="Common Mistakes">

1. **Self-Looping Too Early:** Putting the `10 / 0` loop on $S_1$ instead of $S_2$ implements $(10)^*$ (zero or more) rather than $(10)^+$ (at least one), accepting sequences that skip `10` completely.
2. **Blind Reset to $S_0$:** Sending every non-advancing input back to $S_0$ loses partial prefixes (such as $S_1 \xrightarrow{11/0} S_1$ or $S_3 \xrightarrow{10/0} S_2$) and fails overlap grading checks.
3. **Annotating Outputs Inside Nodes:** Writing $S_k / u$ inside circles instead of $xy / u$ on arcs draws a Moore machine rather than a Mealy machine.
4. **Missing Terminal Overlap:** If a sequence starts with `00` and ends with `00`, returning the `00 / 1` arc to $S_0$ instead of $S_1$ misses back-to-back overlapping frames.

</Callout>

<summary>Reveal Worked Solution</summary>

1. **State Prefix Definitions (8 States):**
   Unlike the January 2026 problem where both branches terminated on `00`, here Branch A terminates on `10` while Branch B terminates on `00`, so their final `(01)+` loops must stay separate ($S_5$ vs. $S_7$):
   - **$S_0$:** Reset ($\varepsilon$), awaiting `00`.
   - **$S_1$:** Matched opening `00`. (`01` forks to Branch A $S_2$; `10` forks to Branch B loop $S_4$; `00` stays in $S_1$).
   - **$S_2$:** Branch A prefix `{00, 01}`. (`00` enters loop $S_3$).
   - **$S_3$:** Branch A loop `{00, 01, (00)+}` (last symbol is `00`). (`00` self-loops to $S_3$; `01` enters loop $S_5$; `10` forms suffix `{00, 10}` matching Branch B loop $S_4$!).
   - **$S_4$:** Branch B loop `{00, (10)+}`. (`10` self-loops to $S_4$; `00` advances to $S_6$).
   - **$S_5$:** Branch A loop `{00, 01, (00)+, (01)+}`. (`01` self-loops to $S_5$; `10` completes Branch A $\implies \mathbf{S_0 / 1}$; `00` preserves prefix `00` $\implies S_1 / 0$).
   - **$S_6$:** Branch B prefix `{00, (10)+, 00}` (last symbol is `00`). (`01` enters loop $S_7$; `00` preserves prefix `00` $\implies S_1 / 0$; `10` forms suffix `{00, 10}` $\implies S_4 / 0$).
   - **$S_7$:** Branch B loop `{00, (10)+, 00, (01)+}`. (`01` self-loops to $S_7$; `00` completes Branch B and overlaps opening `00` $\implies \mathbf{S_1 / 1}$!).
